### Statistics in Data Science
- The science of collecting, analyzing and presenting data
- Foundational backbone that transforms raw data into reliable insights, powers machine learning algortihm, and validates predictive models

### Types of Statistics
- **Descriptive Statistics:** Summarizes and organizes the main features of a dataset using metrics like central tendancy (mean, median, mode) and dispersion (ariance, standard deviation, range) to make large amount of data understandable

- **Inferential Statistics:** Uses a smaller sample of data to make predictions, test assumptions, or draw cinclusions about a larger populatoin

### Key Statistical Concepts
- **Probablity & Distribution:** Models uncertainity and predicts the likelihood of future events

- **Hypothesis Testing:** Evaluates assumptions or compare groups using tests like t-tests, ANOVA, and chi-squared tests
